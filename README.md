# 321領導力 — App（第一版）

《321建造 教會領導力》三語（繁體／简体／English）陪讀 PWA。無框架、無建置步驟，可直接部署到 GitHub Pages 或任何靜態網頁空間。

## 目錄結構

```
321leadership/
├── index.html          App殼層：五個分頁的HTML結構＋全部CSS
├── app.js               所有邏輯：路由、渲染、想更深元件、工具、AI陪讀、提詞機
├── manifest.json         PWA安裝設定
├── sw.js                 Service Worker（版本化快取＋三語資料背景預載）
├── icons/                 9個尺寸的App圖示（取自書封「基督+群體+聖經」徽章）
├── data/
│   ├── data.zh.json       繁體：55課內容＋想更深題庫（439則）＋詞庫＋工具資料
│   ├── data.zs.json       簡體：同上（想更深題庫已機械轉換為簡體）
│   └── data.en.json       英文：55課內容＋想更深題庫（439則，已全數翻譯上線）＋詞庫＋工具資料
└── scripts/               資料組建腳本（維護用，App執行時不需要）
```

## 已完成的功能（五個分頁）

1. **今日**——推薦下一課、11部總覽、完成度總覽。
2. **課程**——11部55課手風琴瀏覽，逐課閱讀頁含「想更深？」摺疊問答（439則，繁簡英三語皆已上線）、段落畫線筆記、每週宣告輸入、標記完成、上下課導覽。
3. **工具**——
   - 321旅程地圖：八大步驟（資訊→啟示→信服→實踐→檢討→修正→反覆→繁殖）×11部進度視覺化（依你的閱讀、想更深開啟數、宣告、檢核、複訪等行為自動推算）。
   - 領導迷思破解：33則精選迷思卡，橫跨全書11部。
   - 關鍵詞軌跡：追蹤「無己」「謙卑」「順服」「屬神體系」「讓耶穌作王」「920」「235」「反敗為勝」「捨己」在55課中的出現與上下文。
   - 教導誠信檢核：11項固定檢核清單，逐課勾選、自動存檔。
   - 提詞機／小組全螢幕帶領模式：全螢幕深色介面、螢幕喚醒鎖、分段計時、825題（55課×15題）三階段討論題逐題呈現，含★優先度與【必做】標示。
4. **陪讀**——小智．領導力教練，聊天介面已完整串接既有共用代理 `xiaozhi-proxy.spch321.workers.dev`（見下方「已知限制」）。系統提示詞依語言與目前課程動態組裝，遵循5條準則（見 app.js `companionSystemPrompt()`）。
5. **我的**——閱讀進度、宣告簿時間軸、畫線筆記列表、外觀設定（淺色／深色／跟隨系統）。

PWA基礎設施：manifest可安裝、9種尺寸圖示、Service Worker版本化快取＋三語資料背景預載（切換語言時零延遲）、8秒開機守衛（若卡住顯示「重新載入／清除快取」診斷畫面）。深色模式CSS token與淺色完整對應。

3. **尚未部署**：本沙盒環境沒有你GitHub帳號（spch321-sudo）的憑證，無法代為建立repo並啟用GitHub Pages。部署步驟見下方。

## 部署到 GitHub Pages

1. 在 `spch321-sudo` 帳號下新建一個repo，例如 `321leadership`。
2. 把這個資料夾（`321leadership/` 內的 index.html、app.js、manifest.json、sw.js、icons/、data/）上傳到repo根目錄（`scripts/` 資料夾可一併上傳保留，或省略，App執行不需要它）。
3. Repo設定 → Pages → 啟用，Source選 `main` 分支根目錄。
4. 完成後網址會是 `https://spch321-sudo.github.io/321leadership/`，與另外兩個姊妹App同一種網址型態。
5. 之後若更新內容，記得同步遞增 `sw.js` 裡的 `VERSION` 常數，否則已安裝的使用者裝置不會看到更新。
