# 321領導力 — App（第一版）

《321建造 教會領導力》三語（繁體／简体／English）陪讀 PWA。無框架、無建置步驟，可直接部署到 GitHub Pages 或任何靜態網頁空間。

## 目錄結構

**刻意設計成完全沒有子資料夾**——所有檔案都放在同一層（repo根目錄），方便用手機瀏覽器的GitHub網頁版直接上傳，不需要建立/管理data、icons等子資料夾：

```
321leadership/
├── index.html          App殼層：五個分頁的HTML結構＋全部CSS
├── app.js               所有邏輯：路由、渲染、想更深元件、工具、AI陪讀、提詞機
├── manifest.json         PWA安裝設定
├── sw.js                 Service Worker（版本化快取＋三語資料背景預載）
├── icon-72.png ～ icon-512.png   9個尺寸的App圖示（取自書封「基督+群體+聖經」徽章）
├── data.zh.json         繁體：55課內容＋想更深題庫（439則）＋詞庫＋工具資料（四項工具皆為繁體）＋小智題庫（220題）
├── data.zs.json         簡體：同上，全部欄位皆已轉換為簡體（含四項工具資料、小智題庫）
└── data.en.json         英文：55課內容＋想更深題庫（439則）＋詞庫＋工具資料＋小智題庫，皆已全數翻譯上線
```

以上每個檔案都直接上傳到repo根目錄即可，不用放進任何子資料夾。

## 已完成的功能（五個分頁）

1. **今日**——推薦下一課、11部總覽、完成度總覽。
2. **課程**——11部55課手風琴瀏覽，逐課閱讀頁含「想更深？」摺疊問答（439則，繁簡英三語皆已上線）、段落畫線筆記＋筆記編輯＋一鍵「問小智」、每週宣告輸入、標記完成、真人語音朗讀（Azure朗讀優先，裝置內建語音為備援）、字級大小切換（標準／大／特大）、上一課／下一課／回首頁／回目錄導覽。
3. **工具**——
   - 321旅程地圖：八大步驟（資訊→啟示→信服→實踐→檢討→修正→反覆→繁殖）×11部進度視覺化（依你的閱讀、想更深開啟數、宣告、檢核、複訪等行為自動推算）。
   - 領導迷思破解：33則精選迷思卡，橫跨全書11部，繁簡英三語皆已上線。
   - 關鍵詞軌跡：追蹤「無己」「謙卑」「順服」「屬神體系」「讓耶穌作王」「920」「235」「反敗為勝」「捨己」在55課中的出現與上下文，繁簡英三語皆已上線。
   - 教導誠信檢核：11項固定檢核清單，逐課勾選、自動存檔，繁簡英三語皆已上線。
   - 提詞機／小組全螢幕帶領模式：全螢幕深色介面、螢幕喚醒鎖、分段計時、825題（55課×15題）三階段討論題逐題呈現，含★優先度與【必做】標示，繁簡英三語皆已上線。
4. **陪讀**——小智．領導力教練，聊天介面已完整串接既有共用代理 `xiaozhi-proxy.spch321.workers.dev`（見下方「已知限制」）。系統提示詞依語言與目前課程動態組裝，遵循6條準則（見 app.js `companionSystemPrompt()`）。內建「💡範例問題」題庫：11部每部20題共220題精選提問，依目前所讀課別自動定位到對應部別，點一下問題即直接送出提問，繁簡英三語皆已上線。小智每則回答下方都有「收合／展開」（過長的回答預設收合、點一下展開全部）、「收藏」（存進「我的」分頁的「我的收藏」列表，含當時的提問與課別，可長期保存）、「刪除」（把這則回答從當前對話中移除）三個按鈕。
5. **我的**——閱讀進度、宣告簿時間軸、畫線筆記列表、我的收藏（陪讀分頁收藏的小智回答，含當時提問與課別）、外觀設定（淺色／深色／跟隨系統）。

PWA基礎設施：manifest可安裝、9種尺寸圖示、Service Worker版本化快取＋三語資料背景預載（切換語言時零延遲）、8秒開機守衛（若卡住顯示「重新載入／清除快取」診斷畫面，且會依語言正確顯示英／簡／繁文字）。深色模式CSS token與淺色完整對應。「想更深？」摺疊標籤、迷思卡「迷思／其實」標籤等CSS偽元素文字，皆已依 `html[data-lang]` 屬性做三語切換，不會殘留繁體字。

## 已知限制／下一步待辦

1. **小智陪讀與語音朗讀的請求／回應格式為假設值**，尚未實測連線（本沙盒環境對 `*.workers.dev` 無出口網路權限，因此程式碼是依既有 `azure-tts.spch321.workers.dev`／`xiaozhi-proxy.spch321.workers.dev` 共用架構的既定模式撰寫，並在 `extractReplyText()` 中做了防禦性的多格式相容解析）。正式上線前，請先用實際部署環境測一輪對話與朗讀，確認欄位名稱與 `app.js` 中的邏輯一致，不一致就照實際格式微調即可。
2. **畫線筆記自v1.3.9起已改為句子層級**（依「。！？」/「.!?」自動切句，點哪一句畫哪一句，「想更深？」的回答內容也適用），跟學神神學App的體驗一致。少數修辭很長、中間只用逗號／分號／破折號連接、直到句尾才有句號的長句（英文版較常見），會維持整句一起畫線，這是正常的句子判斷結果，不是漏切。
3. **破音字讀音修正表目前只涵蓋使用者提供的對照表中的常用詞語**（繁簡各一份，見 `app.js` 的 `TTS_FIX_ZH`／`TTS_FIX_ZS`，已包含「組長」「長執」「長老」「家長」「增長」「長進」「部長」等ㄓㄤˇ音字詞），是精準的詞語級取代、不是每個字全面覆蓋；若之後聽到其他破音字唸錯，只要照同樣格式（原詞、替代同音詞）加進這兩個陣列即可，會自動套用到所有課程的朗讀。另外，「321」「920」「235」這三個全書專用術語的逐字讀音修正，是獨立用正則比對（`TTS_DIGIT_FIXES`），只認獨立出現（前後不緊接其他數字）的321/920/235；「為大」（誰願為大）已修正唸成ㄨㄟˊ音，並保留「為大使命」這個唯一例外仍唸ㄨㄟˋ音；每課固定10個小標題開頭的「一、」「二、」……「十、」，朗讀時會自動唸成「第一，」「第二，」……的自然口吻，不會唸成孤立的數字。如果之後書裡出現其他需要逐字讀或破音字修正的情況，也可以照同樣方式加進對應的陣列。
4. **陪讀對話內容本身不會保存**（只有點了「收藏」的回答才會存進「我的收藏」並長期保留），切換分頁、重新整理或關閉App都會清空當下的對話——這是刻意的設計（避免手機儲存空間被大量對話塞滿），如果想留住某則回答，記得先點「收藏」。
5. **語音朗讀的「先下載一段就開始念、邊播邊背景下載」架構尚未在真實裝置上實測**：v1.3.5起，朗讀只需等「第一小段」下載完成就會立刻開始播放，不必等整段/整課都下載好；播放的同時，後面的段落會在背景持續預先下載（固定保持領先播放進度2小段），所以正常情況下等到目前這段播完、換下一段時，下一段幾乎都已經下載好了，不會再出現當初「斷斷續續」那種每段之間都要等網路的空檔。每一小段下載後都會存進裝置的Cache Storage，同一段文字重聽（甚至離線時）會直接從裝置取用不必再連網。同時串接MediaSession API讓鎖定畫面／背景播放時能顯示標題與播放控制按鈕。這套「先開播、背景預抓」的做法跟姊妹App「晨讀321」的「逐句播放」模式一致，但本沙盒環境無法連上真正的TTS服務、也無法測試手機鎖屏／切到背景時是否真的能持續播放，正式上線後請實機測試一輪（包含Wi-Fi環境先聽過一次、再切飛航模式或關螢幕確認離線與背景播放都正常；若在訊號很差的環境，理論上偶爾仍可能在换段時聽到極短暫的等待，屬於網路本身的限制，並非程式問題）。
6. **朗讀聲音目前只有3個選項**（每個語言各自一組，見 `app.js` 的 `TTS_VOICE_OPTIONS`）：繁體中文＝雲哲（預設）／雲帆／曉辰；簡體中文＝雲帆（預設）／雲哲／曉辰；英文＝Andrew（預設）／Emma／Brian。繁体與簡體共用同一個Azure Worker、同一批聲音（跟晨讀321一致），若之後想增減聲音選項，照 `TTS_VOICE_OPTIONS` 同樣的格式（id、Azure聲音代碼、顯示名稱）增減即可。**英文版的預設聲音（Andrew）沿用這個App原本的設定，尚未逐一比對晨讀321英文版實際使用的聲音代碼是否完全一致**（本沙盒無法讀取晨讀321英文版的原始碼），若跟您期望的不同，可以直接在「我的」分頁的朗讀聲音選單改成想要的，或告訴我正確的Azure聲音代碼，我再把預設值改過來。

## 部署到 GitHub Pages

1. 在 `spch321-sudo` 帳號下新建一個repo，例如 `321leadership`（若已建立過，直接使用）。
2. 用「Add file → Upload files」把上面列出的所有檔案（index.html、app.js、manifest.json、sw.js、9張icon-*.png、3個data.*.json）直接拖曳/選取上傳到repo**根目錄**——不用建立任何子資料夾，這是刻意設計成這樣以方便手機上傳。若同名檔案已存在，上傳會直接覆蓋更新內容。
3. Repo設定 → Pages → 啟用，Source選 `main` 分支根目錄。
4. 完成後網址會是 `https://spch321-sudo.github.io/321leadership/`，與另外兩個姊妹App同一種網址型態。
5. 之後若更新內容，記得同步遞增 `sw.js` 裡的 `VERSION` 常數，否則已安裝的使用者裝置不會看到更新。
